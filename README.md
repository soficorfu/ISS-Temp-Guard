# ISS-Temp-Guard
Μια μικρή Python εφαρμογή για μέτρηση θερμοκρασίας με sense hat στον ΙSS , σαν εργασία στην Πληροφορική της Γ τάξης 2025-2026 στο Ζάννειο Πρότυπο Γυμνάσιο 

ISS Temp Guard
Απλή εφαρμογή παρακολούθησης θερμοκρασίας με Sense HAT
Μάθημα	Εργασία Mission Space Lab / 3η Γυμνασίου
Πλατφόρμα υλοποίησης	Raspberry Pi 5, Sense HAT, Python, Thonny

Σκοπός της εργασίας
Στην εργασία αυτή σχεδιάζουμε και υλοποιούμε ένα απλό πρωτότυπο σύστημα που παρακολουθεί τη θερμοκρασία σε έναν χώρο όπως ο Διεθνής Διαστημικός Σταθμός (ISS). Η εφαρμογή αξιοποιεί τις δυνατότητες του Sense HAT για μέτρηση θερμοκρασίας και για οπτική ειδοποίηση μέσω της οθόνης LED Matrix. Ο κώδικας θα μεταφερθεί και θα εκτελεστεί σε πραγματικό Raspberry Pi 5 μέσω του Thonny.

1. Ορισμός του προβλήματος
Ποιο είναι το πείραμά μας;
Το πείραμά μας είναι η ανάπτυξη μιας απλής εφαρμογής παρακολούθησης θερμοκρασίας για τον ISS. Η εφαρμογή διαβάζει τη θερμοκρασία από το Sense HAT, εμφανίζει την τιμή στον χρήστη και ενεργοποιεί ειδοποιήσεις όταν η θερμοκρασία βγαίνει έξω από προκαθορισμένα όρια.
Τι θέλουμε να ερευνήσουμε;
Θέλουμε να ερευνήσουμε αν ένα μικρό ενσωματωμένο σύστημα με αισθητήρα θερμοκρασίας μπορεί να αναγνωρίζει έγκαιρα φυσιολογικές και μη φυσιολογικές συνθήκες και να ειδοποιεί άμεσα τον χρήστη με απλό και κατανοητό τρόπο.
Πώς θα ωφελήσει η επίλυση του προβλήματος;
Σε ένα περιβάλλον όπως ο ISS η σωστή θερμοκρασία είναι σημαντική για την άνεση και την ασφάλεια των αστροναυτών. Το ίδιο σκεπτικό μπορεί να εφαρμοστεί και στη Γη σε σχολεία, σπίτια, νοσοκομεία, εργαστήρια ή δωμάτια εξυπηρετητών.

3. Ανάλυση του προβλήματος
Ποιος θα χρησιμοποιήσει το σύστημα;
Το σύστημα θα μπορούσε να χρησιμοποιηθεί από αστροναύτες, τεχνικούς, ερευνητές αλλά και από μαθητές στο πλαίσιο ενός εκπαιδευτικού πειράματος.
Τι θα κάνει το σύστημα;
Θα μετρά περιοδικά τη θερμοκρασία, θα την εμφανίζει, θα ελέγχει αν η τιμή βρίσκεται μέσα σε αποδεκτά όρια και θα δίνει οπτικό alarm όταν απαιτείται.
Πότε θα χρησιμοποιείται;
Η εφαρμογή μπορεί να λειτουργεί συνεχώς ή να εκτελεί ελέγχους κάθε λίγα δευτερόλεπτα, ώστε να προσφέρει σχεδόν πραγματικό χρόνο παρακολούθησης.

4. Ανάλυση σε υποπροβλήματα
Υποπρόβλημα 1 - Ανάγνωση αισθητήρα
Το πρόγραμμα πρέπει να διαβάζει σωστά τη θερμοκρασία από το Sense HAT.
Υποπρόβλημα 2 - Έλεγχος ορίων
Η τιμή της θερμοκρασίας πρέπει να συγκρίνεται με προκαθορισμένα όρια ασφαλείας.
Υποπρόβλημα 3 - Οπτική ειδοποίηση
Το LED Matrix πρέπει να δείχνει διαφορετικό χρώμα για κάθε κατάσταση.
Υποπρόβλημα 4 - Alarm
Το πρόγραμμα πρέπει να ξεχωρίζει την κανονική λειτουργία από την προειδοποίηση και τον συναγερμό.
Υποπρόβλημα 5 - Αποθήκευση
Οι μετρήσεις μπορούν να αποθηκεύονται σε αρχείο CSV για μελλοντική μελέτη.

5. Σχεδιασμός του συστήματος
Υλικό
Raspberry Pi 5, Sense HAT, LED Matrix 8x8.
Λογισμικό
Raspberry Pi OS, Python, Thonny και βιβλιοθήκη sense_hat.
Αισθητήρες
Θα χρησιμοποιηθεί κυρίως ο αισθητήρας θερμοκρασίας του Sense HAT. Προαιρετικά το έργο μπορεί αργότερα να επεκταθεί με υγρασία και πίεση.
Χρήση του LED Matrix
Πράσινο για κατάσταση OK, κίτρινο για WARNING και κόκκινο για ALARM. Παράλληλα μπορούν να εμφανίζονται μικρά μηνύματα όπως OK, WARN και ALARM.
Δεδομένα που αποθηκεύονται
Ημερομηνία και ώρα μέτρησης, τιμή θερμοκρασίας και κατάσταση συστήματος σε αρχείο CSV.
Βασικά υποπρογράμματα
read_temperature(), check_status(temp), display_status(temp, status), save_log(temp, status), main().

6. Προδιαγραφές συστήματος
Λειτουργικές προδιαγραφές
Το σύστημα πρέπει να μετρά τη θερμοκρασία, να ελέγχει τα όρια, να εμφανίζει ειδοποιήσεις και να επαναλαμβάνει τη λειτουργία συνεχώς.
Μη λειτουργικές προδιαγραφές
Το σύστημα πρέπει να είναι απλό, εύχρηστο, αξιόπιστο, γρήγορο και κατάλληλο για μαθητές της 3ης Γυμνασίου.

7. Πίνακας ορίων θερμοκρασίας
Για να λειτουργεί σωστά το σύστημα, ορίζουμε τρεις απλές καταστάσεις:
Κατάσταση	Όρια θερμοκρασίας	Ένδειξη
OK	18°C έως 27°C	Πράσινο LED Matrix
WARNING	16°C έως κάτω από 18°C ή πάνω από 27°C έως 29°C	Κίτρινο LED Matrix
ALARM	Κάτω από 16°C ή πάνω από 29°C	Κόκκινο LED Matrix

10. Επεξήγηση του κώδικα
•	Η συνάρτηση read_temperature() παίρνει δύο μετρήσεις θερμοκρασίας από το Sense HAT και βρίσκει τον μέσο όρο τους, ώστε η ένδειξη να είναι πιο σταθερή.
•	Η συνάρτηση check_status(temp) αποφασίζει αν η θερμοκρασία είναι φυσιολογική, οριακή ή επικίνδυνη.
•	Η συνάρτηση display_status(temp, status) εμφανίζει στο LED Matrix το αντίστοιχο χρώμα και ένα μικρό μήνυμα.
•	Η συνάρτηση save_log(temp, status) αποθηκεύει κάθε μέτρηση σε αρχείο CSV για να μπορούμε αργότερα να τη μελετήσουμε.
•	Η main() επαναλαμβάνει τη διαδικασία συνεχώς κάθε 5 δευτερόλεπτα.

11. Συμπέρασμα
•	Το ISS Temp Guard είναι ένα απλό και κατανοητό εκπαιδευτικό project, κατάλληλο για μαθητές της 3ης Γυμνασίου.
•	Αξιοποιεί βασικές δυνατότητες του Sense HAT, όπως τον αισθητήρα θερμοκρασίας και το LED Matrix, και μπορεί να υλοποιηθεί εύκολα στο Thonny σε πραγματικό Raspberry Pi 5.
•	Στο μέλλον το έργο μπορεί να επεκταθεί με υγρασία, πίεση ή χρήση του joystick για εναλλαγή οθονών.

12. Σημείωση για τη μέτρηση θερμοκρασίας
Στην πραγματική χρήση, η θερμοκρασία που διαβάζει το Sense HAT μπορεί να επηρεάζεται λίγο από τη θερμότητα του ίδιου του Raspberry Pi. Για αυτό στο πρόγραμμά μας χρησιμοποιούμε μέσο όρο από δύο μετρήσεις, ώστε η ένδειξη να είναι πιο σταθερή και πιο ρεαλιστική.
